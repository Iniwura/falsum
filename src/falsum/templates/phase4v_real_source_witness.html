02 / WHY IT MATTERS

A PASS ISN'T
A SECURITY

FALSUM checks whether a specific source-level review is consistent with authentic test evidence. A fixed upstream regression supports a narrow conclusion. It does not prove a real deployment is secure or that a vulnerability is exploitable by a particular attacker.

All 80 possible choices on this page were classified by the repository's Python source-witness checker during the static build. The original test executions are publicly reproducible. No private Anjoman questions, model inference, wallet, network request or independent human gold labels are used.
