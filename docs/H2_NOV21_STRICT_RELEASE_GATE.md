## Remaining quality and competition gates

1. **Independent source adjudication:** Zero verified qualified outside AppSec labels. Asking bots or posting an invitation does not create independent labels.
2. **External developer action:** Zero verified independent candidate model submissions, reproduced trials or retained integrations. The public review issue is an invitation, not adoption.
3. **Telegraph effect:** No newly registered improved network scorer, accepted new ranking row or demonstrated measurement gain. FALSUM contributes useful test material; do not conflate historical Eligible status with evaluator-registration proof.
4. **Discrimination:** The actual published small model returned ABSTAIN on all 3 original Phase 5N tasks, all 12 Phase 5O researcher summaries and all 12 Phase 5P authentic raw-source tasks. A useful material test may detect failures; the evidence does not demonstrate a better trained model.
5. **Mandatory H2 entry:** The final official form and showcase permissions have not been completed. The user-owned GitHub bounties star is not verified. A 2–5 minute demo or organizer-accepted accessible equivalent is not verified. Submission deadline December 1, 2026 at 23:59 UTC.
6. **Live deployment:** The five-stage hosted workbench must retain its latest real production HTTP freshness check after each merge. Phase 5P is a CLI/CI addition, not a live user-upload browser model endpoint. Never invent current Vercel deployment IDs.
